- `images/zynapse-cover.webp`: generated promotional illustration, 1672 × 941 pixels, optimized WebP.
- `images/zynapse-social-preview.png`: 1280 × 720 PNG export of the same artwork, sized for a social preview. It is not a second independent design.

- The cover has no app interface. It is illustration, not a screenshot or evidence of additional functionality.
- Artwork provenance and package notices are described in [RIGHTS.md](../RIGHTS.md).

## Real Android screenshots

`android-home.png`, `android-tools.png` and `android-journal.png` in `screenshots/` were captured from the unmodified signed Zynapse 1.0.0 build 9 APK on an isolated Android 15 emulator on 2026-10-27. The emulator used a fresh data directory, a profile named **Demo**, a newly created **Social Media** habit, and a journal note explicitly describing demo activity. No real account was signed in, no production records were imported, and network access was disabled for demo entry and capture.

These are full-screen captures, not generated interfaces, and have only been losslessly optimized to remove unnecessary PNG metadata. No screen contents, metrics, dates, controls or UI labels were altered. Empty or zero activity is intentional. The screenshots demonstrate a preview build, not an app-store release. Android system UI belongs to the emulator environment.

The application includes the existing fox, mood artwork and user-supplied autumn/crimson decorative scenes. No standalone font files, icon libraries or original wallpaper masters are included.
