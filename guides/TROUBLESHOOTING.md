# Troubleshooting

## There is no download button

The website lists store availability, but no store release is verified. This repository does not currently publish an installer. Avoid unofficial mirrors.

## Android will not install the APK

Check the release's Android minimum, download size and SHA-256. Make sure the download finished and the device has space beyond the APK size. Installation from your browser or file manager may require a per-app Android permission.

A signature mismatch, lower build number or different package may prevent an update. Do not uninstall or clear data to resolve it unless you accept losing local history. See [backup and restore](BACKUP_AND_RESTORE.md).

## Arabic layout direction has not changed

After switching into or out of Arabic, follow the app's restart notice. Fully close the app and reopen it. English and French text changes normally apply immediately.

## Reminders, purchases, ads or cloud sync do not work

These depend on native support, permissions, configuration and external services. Production purchases, ads and account sync have not been verified for public use. Keep using local features if available; do not pay or change devices based on an assumed cloud backup.

## Totals differ between screens

Progress summarizes recorded outcomes and activity. Some other screens use older craving counts, so figures can differ. Savings are estimates. Milestone celebration behavior is also under review. Include the screen names and a small invented example in a report, without sending real notes or exports.

## The companion or a screen behaves unexpectedly

Close and reopen the app. Mention your device model, Android version, app version/build, language, appearance and the exact steps in a bug report. Physical-device and cosmetic combinations are not exhaustively tested.

## Export cannot be restored

The current export is partial JSON text without an in-app import. Keep the original installation. Do not reset data as a troubleshooting step.

For further help, read [Support](../SUPPORT.md). Screenshots must be cropped or redacted to remove names, private notes, notifications and contact information before sharing.
