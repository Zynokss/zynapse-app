# Release status

No public release is published here yet. This page records the verified preview candidate, not a release announcement.

- Package: `com.zynapse.app`.
- Format: signed APK, release variant under the existing internal preview workflow.
- Download size: 90,001,744 bytes (85.8 MiB).
- Manifest minimum: Android 7.0 / API 24; target API 36.
- Architectures: arm64-v8a, armeabi-v7a, x86, x86_64.
- SHA-256: `0ae6fbe62f361225fb6e828dca2f6861016da80fc326f37c469bf8d5450d611c`.
- Signing certificate SHA-256: `c4c39357e6c24796a17ae6d485137365d54f0cf8eaa54352d59d5937baaaebd6`.

Previously recorded emulator checks cover in-place update from build 8, standalone launch, setup with text/numeric keyboards, the first-time guide, saved profile/habit and guide dismissal after cold restart, and Feed/Play reactions. Local preparation rechecked the APK hash, v2 signature, manifest and archive integrity, and installed the same APK on a fresh Android 15 emulator for screenshots. These checks do not establish broad device support or a stable release.

The candidate includes keyboard-aware setup, the first-time app guide, the current warm paper/clay interface, tracking, coping tools, journal, progress and companion interactions. This is a description of the candidate; it is not a complete history of earlier versions.

The APK remains unpublished; publishing this product documentation does not authorize binary distribution. The previously recorded hosted artifact URL is no longer working. There is no verified public download link today. No download host or update feed has been changed.

## Limits before wider distribution

Physical-device testing, broader locale and cosmetic combinations, production account sync, purchase/advertising setup, and complete backup/restore remain unverified or incomplete. Milestone celebrations and some craving counters have known inconsistencies. No iOS or desktop release is verified.
